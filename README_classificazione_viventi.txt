COME AGGIUNGERLO A UN SITO GITHUB PAGES
1. Carica classificazione-viventi.html nella cartella principale del repository oppure nella cartella che contiene le altre pagine.
2. Pubblica/aggiorna il repository come fai normalmente.
3. Apri la pagina aggiungendo /classificazione-viventi.html all'indirizzo del tuo sito.

La pagina è autonoma: non richiede librerie o cartelle aggiuntive. I testi restano affiancati (italiano a sinistra, arabo a destra); prima di iniziare si sceglie la lingua della lettura vocale. Ogni paragrafo ha un pulsante di ascolto indipendente. Le immagini sono caricate da Wikimedia Commons e richiedono una connessione Internet. Ogni immagine ha un collegamento alla pagina del file per scaricare l'originale e leggere i dettagli della licenza.
